# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/randomparity/hmc-mcp/security/advisories/new).
Do not open a public issue or pull request for a suspected vulnerability.

Include the affected behavior or version, reproduction steps, likely impact, and any mitigation you
have identified. Do not include passwords, access tokens, production data, or other secrets in the
report or its attachments.

GitHub privately shares the report with the repository maintainers. The project does not accept
vulnerability reports through a public fallback channel.
